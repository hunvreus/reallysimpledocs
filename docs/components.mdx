# Components

RSD supports optional MDX pages for docs that need Astro components. The default content model is still plain Markdown.

<Callout type="tip" title="Use MDX only when needed">
  Keep normal pages as `.md`. Use `.mdx` for interactive examples, richer layout, or component-library documentation.
</Callout>

## Preview

Use `Preview` when you want to show rendered markup and source code together.

</Preview>

## Steps

Use `Steps` for setup flows.

<Steps>
  <Step title="Install packages">
    Add RSD, Basecoat, and Tailwind CSS to your Astro app.
  </Step>
  <Step title="Create docs">
    Add `docs/docs.json` and one or more Markdown or MDX pages.
  </Step>
  <Step title="Run Astro">
    Start the dev server and open the URL printed by Astro.
  </Step>
</Steps>
