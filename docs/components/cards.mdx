# Card and CardGrid

Use `Card` and `CardGrid` for small groups of related links, concepts, or next actions.

## Usage

<Code
  lang="mdx"
  code={`import { Card, CardGrid } from "reallysimpledocs/components";

<CardGrid>
  <Card title="Markdown" description="The default content format.">
    Best for normal docs pages.
  </Card>
  <Card title="MDX" href="/components/">
    Best for component examples.
  </Card>
</CardGrid>`}
/>

## Options

| Component | Prop | Type | Default | Notes |
| --- | --- | --- | --- | --- |
| `Card` | `title` | `string` | `undefined` | Main card heading. |
| `Card` | `description` | `string` | `undefined` | Muted text below the title. |
| `Card` | `href` | `string` | `undefined` | Renders the card as a link. |
| `Card` | `class` | `string` | `""` | Extra classes applied to the card root. |
| `CardGrid` | `class` | `string` | `""` | Extra classes applied to the grid root. |
