import { Callout, Code } from "reallysimpledocs/components";

# Callout

Use `Callout` for important notes, warnings, and destructive or irreversible actions. It maps to Basecoat alert styles and supports documentation-specific variants.

## Usage

<Code
  lang="mdx"
  code={`import { Callout } from "reallysimpledocs/components";

<Callout type="tip" title="Good to know">
  Keep normal docs pages as Markdown.
</Callout>`}
/>

## Examples

<Callout type="note" title="Note">
  Use a callout when the surrounding paragraph is not enough.
</Callout>

<Callout type="tip" title="Tip">
  Use MDX only for pages that need components or custom layout.
</Callout>

<Callout type="warning" title="Warning">
  Avoid putting app-only imports in reusable documentation examples.
</Callout>

<Callout type="danger" title="Destructive">
  This variant is for irreversible actions, security risks, or migration warnings.
</Callout>

<Callout type="note" icon={false} title="No icon">
  Set `icon={false}` when the message should read like normal copy.
</Callout>

## Options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `type` | `"note" \| "tip" \| "warning" \| "danger"` | `"note"` | Main variant. |
| `variant` | `"note" \| "tip" \| "warning" \| "danger"` | `undefined` | Alias for `type`; wins when both are set. |
| `title` | `string` | Variant label | Heading displayed in the alert. |
| `icon` | `false` | `undefined` | Set to `false` to hide the icon. |
| `class` | `string` | `""` | Extra classes applied to the alert root. |
