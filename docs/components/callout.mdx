# Callout

Add callouts in two ways: GitHub-style blockquotes in Markdown or MDX, or the `Callout` component in MDX when you need a custom title, icon, or action.

Both use the same styling: neutral for Note and Tip, purple for Important, amber for Warning, and destructive red for Caution.

## Markdown alerts

Use GitHub-style alerts in Markdown or MDX without importing a component:

```md
> [!WARNING]
> This action permanently deletes your data.
```

Supported markers are `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, and `[!CAUTION]`. Put the marker on its own first line inside a blockquote. Each alert gets a title and icon; its body supports normal Markdown. Important uses purple, Warning uses amber, and Caution uses the destructive red variant. Note and Tip use the neutral appearance.

> [!NOTE]
> Use alerts for information readers should notice.

> [!TIP]
> Keep the message short and actionable.

> [!IMPORTANT]
> Include required setup before readers continue.

> [!WARNING]
> Review your changes before applying them.

> [!CAUTION]
> Deleting data cannot be undone.

Use `Callout` when you need a custom title, icon, or action. Ordinary blockquotes and unsupported markers keep their normal appearance. Code examples are never converted to alerts.

## MDX component

### Usage

Use the component directly in MDX. ReallySimpleDocs components are available by default, so no import is required.

```tsx
<Callout title="Good to know">
  Keep normal docs pages as Markdown. Use MDX when you need components.
</Callout>
```

Set a custom Lucide icon with `icon` when the message benefits from one:

```tsx
<Callout icon="sparkles" title="Custom icon">
  Use any Lucide icon name in camelCase or kebab-case.
</Callout>
```

### Options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `type` | `"warning"` \| `"important"` \| `"destructive"` | `undefined` | Optional severity variant. |
| `title` | `string` | `"Note"` | Heading displayed in the alert. |
| `icon` | `string` | `undefined` | Optional Lucide icon name or custom SVG. |
| `action` | `{ label: string; href: string }` | `undefined` | Optional callout action link. |
| `class` | `string` | `""` | Extra classes applied to the alert root. |
