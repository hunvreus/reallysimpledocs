# Preview

Use `Preview` to show a rendered example and its source in standard Basecoat tabs. Supply the source explicitly with `code` and put the rendered content in the default slot.

## Usage

```mdx
export const buttonSource = `<button type="button" class="btn">Save changes</button>`;

<Preview code={buttonSource} lang="html">
  <button type="button" class="btn">Save changes</button>
</Preview>
```

## Options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `code` | `string` | Required | Source displayed in the Code tab. |
| `lang` | `string` | `"html"` | Language passed to Shiki. |
| `title` | `string` | `"Preview"` | Label for the rendered-example tab. |
| `class` | `string` | `""` | Extra classes on the preview canvas. |

Use ordinary classes such as `flex items-center justify-center` to position the example. Scripts and other example behavior are authored by the page, using normal MDX or imported components.
