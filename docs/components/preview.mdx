# Preview

Use `Preview` for component examples where readers need to see the rendered result and the source code together.

## Usage

<Code
  lang="mdx"
  code={`import { Preview } from "reallysimpledocs/components";

<Preview code={source} lang="html">
  <button type="button" class="btn">Save changes</button>
</Preview>`}
/>

## Examples

<Preview code={buttonSource} lang="html">
  <button type="button" class="btn">Save changes</button>
</Preview>

<Preview code={astroConfig} lang="js" title="astro.config.mjs" defaultTab="code">
  <Callout type="tip" title="Configuration">
    This example opens on the source tab.
  </Callout>
</Preview>

## Options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `code` | `string` | `""` | Source shown in the code tab. |
| `lang` | `string` | `"html"` | Language passed to Shiki. |
| `title` | `string` | `undefined` | Label for the preview tab. |
| `defaultTab` | `"preview" \| "code"` | `"preview"` | Initial active tab. |
| `class` | `string` | `""` | Extra classes applied to the preview canvas. |
