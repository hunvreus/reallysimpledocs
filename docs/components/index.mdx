# Components

RSD ships Markdown directives and MDX components for documentation pages that need richer examples than plain Markdown. They are thin renderers built on Basecoat primitives where possible.

Use `.md` for normal pages and first-class directives like callouts and code groups. Use `.mdx` when a page needs custom Astro components or component-level control.
