# Components

RSD ships MDX components for documentation pages that need richer examples than plain Markdown. They are thin Astro components built on Basecoat primitives where possible.

Use `.md` for normal pages. Use `.mdx` when a page needs components. Common RSD components are available by default, so page-level imports are not required.
