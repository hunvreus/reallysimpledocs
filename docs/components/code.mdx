# Code

Use `Code` for a single syntax-highlighted code block. Use [`CodeGroup`](/components/code-group/) when the same example has package-manager, framework, or platform variants.

## Usage

<Code
  lang="mdx"
  code={`<Code title="Install" lang="bash" code={installCommand} />`}
/>

## Options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `code` | `string` | `""` | Code to highlight. |
| `lang` | `string` | `"text"` | Language passed to Shiki. |
| `title` | `string` | `undefined` | Optional header label. |
| `class` | `string` | `""` | Extra classes applied to the code wrapper. |
