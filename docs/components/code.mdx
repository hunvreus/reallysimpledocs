# Code

Use `Code` for a single syntax-highlighted code block. Use `CodeGroup` when the same example has package-manager, framework, or platform variants.

## Usage

<Code
  lang="mdx"
  code={`import { Code } from "reallysimpledocs/components";

<Code title="Install" lang="bash" code={installCommand} />`}
/>

## Examples

<Preview code={installCodeSource} lang="mdx" defaultTab="code">
  <Code title="Install" lang="bash" code={installCommand} />
</Preview>

<Preview code={configCodeSource} lang="mdx" defaultTab="code">
  <Code title="astro.config.mjs" lang="js" code={astroConfig} />
</Preview>

## Options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `code` | `string` | `""` | Code to highlight. |
| `lang` | `string` | `"text"` | Language passed to Shiki. |
| `title` | `string` | `undefined` | Optional header label. |
| `class` | `string` | `""` | Extra classes applied to the code wrapper. |

## Tabbed code

Use `CodeGroup` for compact tabbed code blocks.

<Code
  lang="mdx"
  code={`import { CodeGroup } from "reallysimpledocs/components";

<CodeGroup
  tabs={[
    { label: "npm", lang: "bash", code: "npm install reallysimpledocs@beta" },
    { label: "pnpm", lang: "bash", code: "pnpm add reallysimpledocs@beta" },
  ]}
/>`}
/>

### CodeGroup options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `tabs` | `{ label, lang?, code, value? }[]` | `[]` | Tabbed code entries. |
| `defaultTab` | `string` | First tab | Initial active tab value. |
| `class` | `string` | `""` | Extra classes applied to the wrapper. |
