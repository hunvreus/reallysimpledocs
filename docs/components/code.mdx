# Code

Use `Code` for a single syntax-highlighted code block. Use `CodeGroup` when the same example has package-manager, framework, or platform variants.

## Usage

```mdx
<Code title="Install" lang="bash">
  npm install reallysimpledocs
</Code>
```

## Options

### Code

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `lang` | `string` | `"text"` | Language passed to Shiki. |
| `title` | `string` | `undefined` | Optional header label. In a `CodeGroup`, this becomes the tab label. |
| `class` | `string` | `""` | Extra classes applied to the wrapper. |

### CodeGroup

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `class` | `string` | `""` | Extra classes applied to the wrapper. |

`CodeGroup` expects child `Code` blocks with a `title`; untitled `Code` blocks are ignored because there is no tab label.
