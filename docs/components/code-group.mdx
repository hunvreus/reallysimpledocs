# CodeGroup

Use `CodeGroup` for tabbed code examples, usually package-manager commands or platform-specific snippets. Use `Code` for a single snippet.

## Usage

<Code
  lang="mdx"
  code={`import { CodeGroup } from "reallysimpledocs/components";

<CodeGroup
  tabs={[
    { label: "npm", lang: "bash", code: "npm install reallysimpledocs@beta" },
    { label: "pnpm", lang: "bash", code: "pnpm add reallysimpledocs@beta" },
  ]}
/>`}
/>

## Options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `tabs` | `{ label, lang?, code, value? }[]` | `[]` | Tabbed code entries. |
| `defaultTab` | `string` | First tab | Initial active tab value. |
| `class` | `string` | `""` | Extra classes applied to the wrapper. |
