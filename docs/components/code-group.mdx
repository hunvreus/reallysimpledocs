# CodeGroup

Use `CodeGroup` for tabbed code examples, usually package-manager commands or platform-specific snippets. Use `Code` for a single snippet.

## Usage

Use the component directly in MDX. RSD components are available by default, so no import is required.

```tsx
<CodeGroup>
  <Code title="npm" lang="bash">npm install reallysimpledocs@beta</Code>
  <Code title="pnpm" lang="bash">pnpm add reallysimpledocs@beta</Code>
</CodeGroup>
```

## Options

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `defaultTab` | `string` | First tab | Initial active tab value. |
| `class` | `string` | `""` | Extra classes applied to the wrapper. |
